# Worship Pads

Player de pads ambientes para louvor ao vivo: loop sem emenda, transposição em semitons, LIVE MODE, importação de WAV/MP3/FLAC e criador de pads.

**Abrir:** https://lucaslemos1660-coder.github.io/worship-pads/

## Instalar no Android

1. Abra o endereço acima no Chrome.
2. Toque em ⋮ → **Instalar app**.
3. Use pelo ícone na tela inicial. Depois da primeira abertura, funciona sem internet.

Este repositório tem só a versão publicada do app. O código-fonte modular e os testes ficam no pacote `worship-pads-1.0.0.zip`.
